Driver Drowsiness Detection is an end-to-end deep learning application that determines whether a driver is awake or falling asleep, with the goal of preventing fatigue-related accidents.

**Highlights**

* CNN classifier trained with TensorFlow, reaching 96% accuracy.
* Image processing with OpenCV.
* Django web application where images can be uploaded for prediction, plus documented REST APIs and an admin panel.

**Tech stack:** Python · TensorFlow · CNN · OpenCV · Django
