This project aims to predict whether a Near-Earth Object (NEO) is potentially hazardous using machine learning. Leveraging a dataset of NEO observations from 1910 to 2024, it classifies objects based on various features into hazardous or non-hazardous categories, providing a robust solution to enhance NEO risk assessment.

**Tech stack:** Python · Pandas · Scikit-learn · PyCaret · Streamlit · Lime · Skops
