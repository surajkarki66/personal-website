As part of an [Omdena](https://www.omdena.com/) AI innovation project, I contributed to an AI-driven system that predicts dengue fever outbreaks in Sri Lanka. Using time-series analysis and machine learning, the system improves early-warning capabilities so public health authorities can respond sooner and allocate resources more efficiently.

**Highlights**

* Time-series forecasting of dengue cases with Darts and Scikit-learn.
* Model explanations with SHAP to show which factors drive predicted outbreaks.
* Forecasts served through an interactive Streamlit dashboard.

**Tech stack:** Python · Pandas · Darts · Scikit-learn · SHAP · Streamlit
