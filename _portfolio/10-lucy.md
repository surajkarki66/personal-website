![Lucy](/images/portfolio/lucy.jpg)

Lucy is an NLP-powered chatbot that holds conversations with users and answers questions about Nepal Engineering College, making college information easier to access for students and visitors.

**Highlights**

* End-to-end deep learning project: NLP model built with PyTorch and Transformers, reaching around 90% accuracy.
* FastAPI REST backend with PostgreSQL and JWT authentication, and a React + Material UI chat interface, deployed with Docker.
* Published as a journal article: [Bridging the Gap in College Information Access Through Natural Language Processing Powered Lucy Chatbot](/publication/2024-01-01-lucy-nlp-chatbot).

**Tech stack:** PyTorch · Transformers · Scikit-learn · FastAPI · PostgreSQL · React.js · Material UI · Docker
