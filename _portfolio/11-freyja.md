Freyja is a full-stack web application that grades essays automatically using an LSTM model. It is an end-to-end deep learning application, from training the NLP model to serving predictions through a web interface.

**Highlights**

* LSTM essay-scoring model trained on the [Hewlett Foundation Automated Essay Scoring](https://www.kaggle.com/mpwolke/hewlett-foundation-essay-scoring) dataset.
* Django REST backend and React frontend, deployed with Docker and Nginx.
* [Education category winner at Quantum Hack 2020](/files/QH_HackathonWinner-Freyja-Suraj.pdf), a 24-hour hackathon with 240 participants from around the world.

**Tech stack:** Python · TensorFlow · LSTM · Gensim · spaCy · Django REST · React.js · Docker · Nginx
